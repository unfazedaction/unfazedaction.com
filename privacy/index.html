Second Brain web workspace

The existing web workspace uses Firebase authentication for UA Account sign-in and Cloud Firestore to synchronize saved entries and checklists. The workspace provides individual item deletion and a JSON data export option. These controls do not represent a complete account deletion process.

For your own privacy, sign out on shared computers. Keep exported files private.
